# 10x Content Framework

Making a page unique and authoritative enough to beat what already ranks.

| Lever | What to do |
|---|---|
| **Most comprehensive** | List every subtopic covered by the top 3–4 results; close every gap and add one they all miss. |
| **Most authoritative** | SME author linked to an author page or LinkedIn profile; expert quotes; sensible internal links; embedded related videos; links to whitepapers or original data. |
| **Easiest to understand** | You'll answer the same questions as competitors, so answer them in fewer, plainer words. If they say it in two sentences, say it in one. |
| **Most visual** | Custom graphics for bulleted, numbered, or complex sections. A video embedded at the top is a strong boost. |
| **Best title** | Target keyword near the front, plainly describing the content, blended from top-ranking titles. |
| **Best FAQs** | Cast a wider net using PAA plus Semrush/Ahrefs question data. |
| **At a Glance** | A bulleted overview between the H1 and intro (Business Insider style) helps engines and LLMs grasp scope fast. |

## Approachability review (for AI-assisted drafts)
- Prompt inputs should explicitly exclude fluff, buzzwords, marketing speak, and hollow language.
- Use contractions ("here's", not "here is").
- Speak to the reader in second person if the brand guide allows.
- Chunk walls of text and smooth transitions.
