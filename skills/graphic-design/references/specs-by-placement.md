# Specs by Placement

Platform specs change often. Confirm the current specs in each platform's help center before final export.

| Placement | Common size | Notes |
|---|---|---|
| LinkedIn feed image (organic or ad) | 1200×1200 (1:1) or 1200×1500 (4:5) | Square or vertical takes more space in the mobile feed |
| LinkedIn document/carousel | 1080×1350 (4:5) PDF pages | Big, readable text; 6–12 pages |
| Meta feed | 1080×1350 (4:5) or 1080×1080 | Keep key elements away from edges |
| Stories / Reels / Shorts / TikTok | 1080×1920 (9:16) | Leave safe zones top and bottom for UI overlays |
| YouTube thumbnail | 1280×720 | Readable at small size; faces and few words |
| Display ads | 300×250, 728×90, 160×600, 320×50, 300×600 | Logo, headline, CTA; file size limits apply |
| Email header | 600–640px wide | Live text for key messages; images may be blocked |
| Blog featured image | 1200×630 | Also used as the social share (Open Graph) image |
| One-pager | Letter (8.5×11 in) or A4 | Export print PDF with bleed when printing professionally |
| Slides | 1920×1080 (16:9) | One idea per slide |
