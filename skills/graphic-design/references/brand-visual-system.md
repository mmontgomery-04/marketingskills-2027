# Brand Visual System

## Minimum viable system
- **Logo:** primary, secondary (icon), clear space, minimum size, and versions for light and dark backgrounds.
- **Color:** 1 primary, 1–2 secondary, a neutral scale (5–7 grays), and functional colors (success, warning, error). Record HEX, RGB, and CMYK values and check contrast pairs.
- **Typography:** one typeface for headings and one for body (or a single family with several weights); a type scale (e.g. 48 / 32 / 24 / 18 / 16 / 14); line height around 1.4–1.6 for body text.
- **Imagery:** photography style (real people and real product beats generic stock), illustration style, and icon set.
- **Layout:** a grid (e.g. 12-column for web, 8px spacing scale), margins, and alignment rules.
- **Data visualization:** chart color order, how to highlight the key data point, and label rules.
- **Templates:** social post, ad, one-pager, slide master, email header, and event banner.

Put the system in one shared document or design-tool library so every asset starts from the same parts.
