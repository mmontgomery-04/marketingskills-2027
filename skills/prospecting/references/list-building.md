# List Building

- Start narrow: one segment, one persona, one trigger. Broad lists produce generic emails.
- Pull accounts first, then contacts; dedupe against the CRM (open opportunities, customers, recent touches).
- Verify emails (ZeroBounce, NeverBounce, or built-in verification) and remove role addresses for cold email.
- Enrich with Clay waterfalls for coverage across providers.
- Size check: Tier 1 ~50–100 accounts per AE; Tier 2 a few hundred; Tier 3 programmatic.
- Respect opt-outs and regional rules (see cold-email infrastructure notes).
