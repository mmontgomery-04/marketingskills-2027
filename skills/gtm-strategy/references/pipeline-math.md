# Pipeline Math

```
New ARR target        = $3,000,000
Average deal size     = $30,000   → 100 deals needed
Win rate (SQO→won)    = 25%       → 400 SQOs
SQL→SQO               = 60%       → ~667 SQLs
MQL→SQL               = 30%       → ~2,222 MQLs
Pipeline coverage     = 3–4× target
```
Split by source (inbound, outbound, partner, events) using historical mix, then by quarter accounting for sales cycle length (pipeline created in Q1 closes in Q2–Q3 if the cycle is 90–180 days).

Use your own conversion rates from the CRM. If you don't have them, label any assumption clearly and recalibrate after one quarter.
