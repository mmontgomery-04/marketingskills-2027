# GTM Motions

ACV thresholds below are rough rules of thumb, not hard cutoffs.

| Motion | Fits when | Core engine | Key metrics |
|---|---|---|---|
| **Product-led (PLG)** | Low ACV (<$10K), fast time to value, end user can adopt alone | Free/trial → activation → upgrade, PQLs | Activation rate, PQL→paid, expansion |
| **Sales-led** | High ACV ($25K+), complex buying committee, security reviews | Outbound + inbound demos → AE cycle | Pipeline, win rate, cycle length |
| **ABM** | Concentrated TAM, large deals, defined account list | Coordinated ads, outreach, events per account | Account engagement, pipeline per tier |
| **Partner-led** | Partners own the customer relationship (SIs, resellers, marketplaces) | Co-selling, marketplace listings, referrals | Partner-sourced pipeline |
| **Community-led** | Practitioner audience that learns from peers | Community, content, events → product | Community-influenced pipeline |
| **Hybrid (PLG + sales)** | Self-serve entry with enterprise upside | PQL routing to sales-assist | PQL→opportunity conversion |
