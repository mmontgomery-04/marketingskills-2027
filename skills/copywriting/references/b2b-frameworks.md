# B2B Copy Frameworks

| Framework | Structure | Best for |
|---|---|---|
| **PAS** | Problem → Agitate → Solution | Cold email, ads, problem-aware landing pages |
| **AIDA** | Attention → Interest → Desire → Action | Long-form landing pages, video scripts |
| **BAB** | Before → After → Bridge | Case studies, social posts, short ads |
| **4Ps** | Promise → Picture → Proof → Push | Sales pages, one-pagers |
| **StoryBrand** | Hero (customer) has a problem → meets guide (you) → plan → CTA → success/failure stakes | Homepages, brand messaging |
| **JTBD** | "When [situation], I want to [motivation], so I can [outcome]" | Value props, feature pages, positioning |
| **FAB** | Feature → Advantage → Benefit | Product pages, spec sheets, technical audiences |
| **QUEST** | Qualify → Understand → Educate → Stimulate → Transition | Nurture emails, webinars |

## Writing for the buying committee
| Reader | Cares about | Lead with | Proof they trust |
|---|---|---|---|
| Economic buyer (VP/C-level) | Revenue, cost, risk, time to value | Business outcome + ROI | Peer logos, analyst reports, ROI figures |
| Champion (manager) | Looking good, hitting goals, easy rollout | Their KPI + how easy adoption is | Case studies from similar teams |
| Technical evaluator | Security, integrations, architecture, effort | Specs, docs, integration list | Documentation, SOC 2, API references |
| End user | Less busywork, ease | Day-in-the-life improvement | Reviews, demos, screenshots |
| Procurement/legal | Terms, compliance, vendor risk | Compliance and pricing clarity | Certifications, standard contracts |

Multi-reader assets (e.g. homepages) lead with the economic outcome and give each other reader a clear path ("For IT teams →").
