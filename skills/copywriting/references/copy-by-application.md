# Copy by Application

## Homepage
Hero (headline = outcome, subhead = who + how, primary CTA + secondary CTA) → social proof bar → problem → solution/3 pillars → how it works → proof (case study, metrics) → use cases/personas → integrations → objection handling/FAQ → final CTA.

## Landing page (paid/campaign)
One audience, one offer, one CTA. Match the headline to the ad's promise. Remove global nav. Above the fold: headline, subhead, proof, CTA or form.

## Product/feature page
FAB or JTBD. Lead with the job it does, then show it (screenshot/GIF), then specs, then proof.

## Comparison/alternative page
Be fair and specific; a table of 8–12 attributes; "best for" statements for each; why customers switch; migration help.

## Search ads
Headlines ≤30 chars, descriptions ≤90 chars. Include the keyword, a differentiator, and a CTA. Write 10–15 headlines for RSAs with varied angles (benefit, proof, offer, urgency).

## Social ads
Hook in the first line or first 3 seconds; one idea per ad; native-looking creative; CTA matches the offer.

## Emails
Subject (≤45 chars, specific) + preview text that complements it. One idea, one CTA. Plain-text style performs well in B2B.

## Sales one-pager
Headline outcome → problem → solution in 3 bullets → proof (metric + logo) → how it works → CTA/contact. Fits one page and is scannable in 30 seconds.

## Case study
BAB: customer snapshot → challenge → why they chose us → implementation → results (numbers) → quote → CTA.

## Social posts (organic LinkedIn)
Hook line → white space → one insight or story → takeaway → soft CTA or question. Test link placement (in post vs first comment) on your own account; platform behavior changes, so trust your data over folklore.

## Video script
Hook (0–5s) → problem → solution demo → proof → CTA. Write for the ear: short sentences.

## Microcopy
Buttons as verbs + outcome ("Start free trial"). Error messages say what happened and how to fix it. Empty states teach the next action.
