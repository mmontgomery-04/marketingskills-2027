# Event Marketing

## Before You Start

1. **Load shared context.** If `.agents/marketing-context.md` exists, read it first and only ask for what's missing. If it doesn't exist, offer to run the [marketing-context](../marketing-context/SKILL.md) skill (5–10 minutes) or proceed with a few quick questions.
2. **Confirm the job.** Restate the task, the audience, and what "done" looks like in one or two sentences before producing work.
3. **Write like a person.** Any copy you produce (emails, posts, ads, pages, briefs) follows the [copywriting's Don'ts](../copywriting/SKILL.md): no em dashes, no "it's not X, it's Y" framing, no choppy fragment stacks or repetition for effect; use flowing prose in second person with contractions.

## Workflow

### 1. Goal and format
| Goal | Best formats |
|---|---|
| Pipeline from target accounts | Executive dinners, roundtables, private workshops |
| Lead volume | Webinars, virtual summits, trade show booths |
| Brand / category leadership | Speaking slots, own conference, research launch |
| Customer expansion and retention | User conference, customer advisory boards |

### 2. Plan
- Webinars: [webinar-playbook.md](references/webinar-playbook.md)
- In-person (trade shows, field events, dinners): [field-events.md](references/field-events.md)

### 3. Promote
Multi-channel: email to segmented lists, organic social (company + speakers + employees), paid social to ICP audiences, partner/co-host promotion, sales personal invites for target accounts.

### 4. Run
Run-of-show, roles, tech check, lead capture method (badge scans, forms, notes fields for context).

### 5. Follow up fast
Within 24–48 hours. Segment by engagement (attended / no-show / booth conversation quality / meeting booked). Sales follows up on hot leads personally the next day; routing follows revops rules.

### 6. Measure ROI
Registrations, attendance rate, meetings booked, pipeline sourced and influenced (90–180 days), cost per opportunity, and closed-won revenue.

## Output
Event plan doc: goal → audience → format → agenda → promotion timeline → budget → lead capture → follow-up plan → success metrics.
