# Social Metrics Definitions

| Metric | Formula / definition |
|---|---|
| Engagement rate (by impressions) | (reactions + comments + shares + clicks + saves) ÷ impressions |
| Engagement rate (by followers) | engagements ÷ followers (useful for cross-account comparison) |
| Follower growth rate | new followers ÷ starting followers, per period |
| ICP follower share | followers matching ICP seniority/function/industry ÷ total (from page demographics) |
| CTR | clicks ÷ impressions |
| Cost per lead (paid) | spend ÷ leads |
| Cost per opportunity (paid) | spend ÷ opportunities attributed |
| Social-influenced pipeline | pipeline from contacts/accounts that engaged with social before opp creation |
| Self-reported social attribution | % of demo requests that mention social/LinkedIn/a person in "How did you hear about us?" |
| Share of voice | your brand mentions ÷ total category mentions (via listening tool) |

Platforms define "impressions", "reach", and "engagement" differently. Note the source next to each number.
