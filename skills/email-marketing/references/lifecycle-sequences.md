# Lifecycle Sequences

## Core B2B flows
| Flow | Trigger | Length | Goal |
|---|---|---|---|
| Welcome (newsletter) | Subscribe | 3 emails / 7 days | Set expectations, deliver best content, first engagement |
| Content nurture | Lead magnet download | 4–6 / 3 weeks | Move MOFU → BOFU action |
| Trial onboarding | Trial start | 5–7 / trial length | Reach activation milestone (the "aha") |
| Trial-to-paid | Day N or usage milestone | 3–4 | Convert; handle objections |
| Demo no-show | Missed meeting | 2–3 / 5 days | Reschedule |
| Closed-lost recycle | Opp closed-lost | Quarterly touches | Re-open when timing changes |
| Customer onboarding | Closed-won | 4–6 / 30 days | Adoption and time to value |
| Re-engagement | 90 days inactive | 2–3 | Re-engage or sunset to protect deliverability |

## Segmentation dimensions
Lifecycle stage · persona/role · industry · company size · product interest · engagement score · customer vs prospect.

## Newsletter rules
Consistent day and time; one main story plus 2–3 short items; a recognizable format; a human sender name; the reply is a feature, invite it.
