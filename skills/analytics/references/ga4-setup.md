# GA4 Setup Checklist

- [ ] One property per brand/site; data streams for web (and app if any)
- [ ] Data retention set to 14 months
- [ ] Internal and developer traffic filtered; unwanted referrals excluded (payment processors, SSO domains)
- [ ] Cross-domain measurement for marketing site ↔ app ↔ booking tools
- [ ] Enhanced measurement reviewed (disable form interactions if they double-count your custom events)
- [ ] Key events marked; values assigned where meaningful
- [ ] Custom dimensions registered for event parameters you report on
- [ ] Custom channel group including an "AI Assistants" channel (chatgpt.com, perplexity.ai, gemini.google.com, copilot.microsoft.com, claude.ai)
- [ ] Linked to Google Ads, Search Console, and BigQuery (export for raw analysis)
- [ ] Consent Mode v2 configured with your CMP
