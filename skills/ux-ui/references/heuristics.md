# Usability Heuristics (B2B Lens)

1. **Visibility of system status:** loading states, progress in multi-step forms and onboarding, save confirmations.
2. **Match the real world:** use the customer's terms, not internal product names.
3. **User control and freedom:** undo, cancel, back without losing data.
4. **Consistency and standards:** same component, same behavior, everywhere.
5. **Error prevention:** constraints, defaults, confirmation for destructive actions.
6. **Recognition over recall:** visible options, recent items, contextual help.
7. **Flexibility and efficiency:** keyboard shortcuts, bulk actions, saved views for power users.
8. **Aesthetic and minimalist design:** every element competes for attention; remove what doesn't serve the task.
9. **Help users recover from errors:** plain-language messages that say how to fix it.
10. **Help and documentation:** searchable, task-based, in context.
