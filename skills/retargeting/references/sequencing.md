# Creative Sequencing

Move each segment one step forward instead of jumping straight to "Book a demo" for everyone.

| Segment | Message angle | Offer |
|---|---|---|
| Content readers | Deeper education on the same topic | Guide, template, webinar |
| Proof seekers | Results from a similar company | Case study, ROI calculator |
| Product interest | How it works for their use case | Product tour, short demo video |
| High intent | Answer the likely objection (price, security, migration effort, time to value) | Demo, trial, talk to an expert |
| Trial abandoners | Help them reach first value | Setup help, onboarding session |
| Closed-lost (90+ days) | What's new since they evaluated | Updated demo, new feature tour |

## Frequency and fatigue
- Start with roughly 3–7 impressions per person per week on hot segments and fewer on cool ones, then adjust based on results and platform tools.
- Rotate 3–5 creatives per segment and refresh when click-through rates fall steadily.
- Mix formats (single image, video, document, Thought Leader ads) so the same person doesn't see the same ad repeatedly.
