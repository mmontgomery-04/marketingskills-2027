# Account Structure

```
Account
├─ Brand – Search (exact/phrase brand terms)
├─ Non-brand – High Intent – [Theme A] (e.g. "soc 2 compliance software")
├─ Non-brand – High Intent – [Theme B]
├─ Competitor – Search (competitor names → comparison pages)
├─ Non-brand – Problem-aware (lower bids, content/lead-magnet offers)
├─ Remarketing / RLSA (layer audiences on broader terms)
└─ Performance Max (only with strong conversion data and brand exclusions)
```
- Separate brand from non-brand so brand doesn't mask non-brand performance.
- Split geos only when budgets, languages, or economics differ.
- Name consistently: `[Network]_[Type]_[Theme]_[Geo]`.
- Performance Max: add brand exclusions, feed it pipeline-quality conversion signals, and review search-term insights and placement reports. Without good signals it can drift into low-quality leads.
