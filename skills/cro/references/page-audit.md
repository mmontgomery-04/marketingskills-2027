# Landing Page Audit

| Area | Questions |
|---|---|
| **Message match** | Does the headline match the ad/email/link that sent the visitor? |
| **Clarity (5-second test)** | Can a stranger say what it is, who it's for, and what to do next? |
| **Value proposition** | Outcome-led? Specific? Differentiated? |
| **Proof** | Logos, metrics, testimonials, ratings near the CTA? |
| **CTA** | One primary action, visible above the fold, specific text? |
| **Friction** | Form length, required fields, slow load, popups, layout shift? |
| **Objections** | Pricing, security, integration, effort: answered on page? |
| **Visual hierarchy** | Does the eye path lead to the CTA? Enough contrast? |
| **Mobile** | Thumb-friendly CTA, readable text, form usable? |
| **Trust** | Security badges, privacy note by the form, real photos, contact info? |
| **Speed** | LCP under 2.5s on mobile? |

Score each 0–2; anything at 0 is a fix-now item.
