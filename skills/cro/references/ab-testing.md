# A/B Testing

## Hypothesis format
> Because we observed [evidence], we believe that [change] for [audience] will [improve metric] because [reason].

## Rules
- One primary metric chosen in advance (e.g. demo requests per visitor), plus guardrail metrics.
- Calculate sample size before launching (baseline rate, minimum detectable effect, 95% significance, 80% power).
- Run in full-week cycles (at least 2 weeks) to avoid day-of-week bias. Don't peek and stop early.
- Low-traffic B2B pages often can't reach significance; test bigger changes (new page vs old page) or use qualitative testing (5-second tests, user interviews) instead.
- Record every test: hypothesis, result, learning. Losing tests teach as much as winners.

## What tends to move B2B conversion most
Message match, offer change (e.g. "see a 2-min demo video" vs "book a demo"), form length, proof placement, and pricing transparency, usually more than button color.
