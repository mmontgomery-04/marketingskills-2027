# Funnel & Pipeline Metrics

| Metric | Formula |
|---|---|
| Stage conversion | stage N+1 ÷ stage N (cohorted by created month) |
| Velocity | (# opps × win rate × avg deal size) ÷ cycle length |
| Pipeline coverage | open pipeline in period ÷ quota |
| CAC | (sales + marketing spend) ÷ new customers |
| CAC payback | CAC ÷ (new MRR × gross margin) |
| Marketing-sourced pipeline | pipeline where first/originating touch = marketing |
| Influenced pipeline | pipeline with any marketing touch before opp creation |
| Win rate | won ÷ (won + lost) |
| NRR | (starting ARR + expansion − contraction − churn) ÷ starting ARR |

## Dashboards
1. **Weekly pipeline:** created vs target by source, stage movement, slipped deals
2. **Funnel health:** conversion rates and time in stage by segment
3. **Marketing performance:** pipeline and CAC by channel and campaign
