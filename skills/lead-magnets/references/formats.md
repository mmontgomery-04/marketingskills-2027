# Lead Magnet Formats

| Format | Stage | Effort | Why it works | Example |
|---|---|---|---|---|
| Checklist | MOFU | Low | Instant utility | "SOC 2 Readiness Checklist" |
| Template / swipe file | MOFU | Low–Med | Saves hours | "RevOps QBR Deck Template" |
| One-pager | MOFU/BOFU | Low | Scannable, shareable internally | Product overview, use-case sheet |
| Infographic | TOFU/MOFU | Med | Shareable, linkable, visual | "State of B2B Pipeline 2026" |
| Guide / ebook | MOFU | High | Depth and authority | "The CFO's Guide to AP Automation" |
| Calculator / ROI tool | BOFU | Med–High | Builds the business case | "Cloud Cost Savings Calculator" |
| Assessment / scorecard | MOFU/BOFU | Med | Personalized result, qualifies the lead | "RevOps Maturity Assessment" |
| Benchmark report | MOFU | High | Original data, PR and AI citation magnet | "2026 SaaS Churn Benchmarks" |
| Buyer's guide / RFP template | BOFU | Med | Shapes evaluation criteria in your favor | "Vendor Evaluation Scorecard" |
| Comparison sheet / battlecard (external) | BOFU | Low | Speeds vendor decisions | "Us vs Them at a Glance" |

## One-pager layout
1. Headline (outcome) + subhead (who it's for)
2. The problem (2–3 lines, customer language)
3. Solution in 3 bullet benefits with icons
4. How it works (3 steps)
5. Proof: one metric + logo or quote
6. CTA + contact/QR code

## Infographic layout
Title → hook stat → 4–7 sections that flow top to bottom (each = one stat or step + icon) → source list → brand + URL. Keep text to ~10% of the area.

## Guide structure
Cover → "who this is for / what you'll get" → TOC → 5–8 chapters (each ending with an action item) → worksheet/checklist → about us + soft CTA.
